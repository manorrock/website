# JSF 2.2 approved

The JSF 2.2 ballot was approved, so now it is time to start 
speaking up about what you think needs to be in JSF 2.2. Obviously 
it takes a bit of time to start organizing the Expert Group. But 
nowadays individuals can join too. So there really is no excuse to 
start contributing. If you do not know how to get started feel free
to comment!
